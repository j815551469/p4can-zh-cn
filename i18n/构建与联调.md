# 中文分支（i18n/zh-cn）· 私有自用

本分支把上游 P4-CAN Universal v3.29.3 的**仪表板界面**整体中文化，并把
固件消息的翻译表、Android 资源一并放在 `i18n/` 下。

> 上游无 LICENSE（默认保留所有权利），因此本仓库**只允许私有使用**：
> 不要公开、不要发布 Release、不要分发固件或 APK。

## 已包含

| 文件 | 说明 |
|---|---|
| `dashboard_source.html` | **中文版**仪表板源（由 `i18n/zh-CN.json` 注入生成） |
| `index_html.h` | 已用 `tools/build_dashboard.py` 重新生成（内含中文 gzip） |
| `i18n/zh-CN.json` | 词表 865 条（key = 英文原文） |
| `i18n/firmware_zh.json` | 固件消息中文表（28 条） |
| `i18n/patch_firmware_zh.py` | 白名单方式替换固件消息（默认 dry-run） |
| `tools/localize.py` | 中文注入工具（文本节点 + 属性 + JS 整串） |
| `tools/build_firmware.py` | **一条命令重编固件**（暂存 → 生成仪表板 → 编译 → 校验） |
| `tools/verify_build.py` | 校验固件里内嵌的仪表板是否中文、是否与 `dashboard_source.html` 一致 |
| `i18n/README-中文化说明.md` | 术语表、用法、进度 |

## 同步上游

```bash
git remote add upstream https://github.com/06066060606060/P4can-universal-unlock.git
git fetch upstream
git merge upstream/main        # 冲突通常集中在 dashboard_source.html
# 重新生成中文仪表板：
python tools/localize.py --src dashboard_source.html --dict i18n/zh-CN.json --out dashboard_source.zh.html
copy dashboard_source.zh.html dashboard_source.html
python tools/build_dashboard.py
# 重新出固件（会顺带校验中文仪表板）
python tools\build_firmware.py
```

> 上游改动后，未命中词表的新文案会进入 `untranslated.csv`，按提示补翻即可。

## 编译烧录（本机工具链已装好）

本机已有 arduino-cli 1.6.0 + Arduino-ESP32 3.3.12（core 数据目录 `C:\arduino-data2`），
一条命令出固件：

```powershell
python tools\build_firmware.py
```

脚本会先把固件源码暂存成 `build/_src/P4-CAN-Universal-v3.29.3/`——arduino-cli 要求
sketch 目录名与 `.ino` 主文件名一致，而本仓库目录叫 `p4can-zh-fork`，直接编会报
`main file missing from sketch`；暂存后再编译，并做两项内容级校验：内嵌中文仪表板
（`tools/verify_build.py`）+ TinyCrypt owner 契约（`src/p4_tinycrypt` 绑定）。
产物在 `build/out/`，发布用的同名文件在 `dist/`。

> **不要**拿“去掉 `src/` 的副本”去编：会丢掉本仓库自带的 TinyCrypt 覆写实现，
> 编出与源码不对应的固件（2026-11-13 14:35 的旧产物就踩过这个坑，详见 `dist/BUILD-INFO.md`）。

手编等价设置：开发板 `ESP32P4 Dev Module`，FQBN：

```
esp32:esp32:esp32p4:ChipVariant=postv3,FlashSize=32M,PartitionScheme=app5M_fat24M_32MB,PSRAM=enabled,USBMode=hwcdc,CDCOnBoot=cdc,FlashMode=qio
```

编译目标：`P4-CAN-Universal-v3.29.3.ino`。烧录后手机连 `T2CAN-****` / `12345678`，
打开 `http://192.168.4.1` 即是中文界面。

## 固件消息中文（可选）

```bash
python i18n/patch_firmware_zh.py            # 预览将改哪些
python i18n/patch_firmware_zh.py --apply    # 应用（自动 *.zh.bak 备份）
python i18n/patch_firmware_zh.py --rollback # 还原
```

注意：仓库自带的 host/browser 测试若断言英文文案，替换后会失败，属预期；
只翻白名单（纯消息），接口枚举值（`SINGLE TX`、`350ms BURST`、`Body CAN A` 等）保持英文。
