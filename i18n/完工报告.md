## 六、2026-11-17 复核与修正

第二轮逐条核对，重点是“中文表达是否准确”，结果如下。

### 1. 先修掉一类真 bug：翻译把逻辑串改了

早期版本的 JS 替换是不看上下文的，把用于比较的字符串也翻了，导致：

| 代码里被翻掉的字面量 | 后果 |
|---|---|
| `state==='READY'` → `'就绪'` | 研究抓包/配对状态判断失效 |
| `__p4CanBName==='CHASSIS'` → `'底盘'` | R79 路由判断失效，永远走 Party 分支 |
| `event.key==='Home'/'End'` → `'首页'/'结束'` | 下拉选择框的 Home/End 键盘导航失效 |
| `mode!=='SNAPSHOT'` → `'快照'` | 抓包模式被误判为原始模式 |
| `document.body.dataset.ap==='AUTOSTEER'` → `'自动转向'` | 转向灯副标题永远显示 NOA 分支 |

`tools/localize.py` 现在会先扫出“数据位置”的字面量并整份保护，`verify_localization.py`
再兜底检查“比较里是否出现中文”。重新生成后，全部逻辑串恢复英文，功能随之复原。

### 2. 表达不准/不通的条目（20 条 + 2 处长句）

- `Applying vehicle profile before CAN initialization…` 原译「正在初始化 CAN 前应用…」→
  **正在 CAN 初始化前应用车型档案…**
- `AUTO LEFT OPEN / BLOCKED` 原译「自动 左开 / 阻塞」→ **自动：左变道开放 / 阻塞**
  （LEFT_OPEN 指 `DAS_autoLaneChangeState` 允许左变道，不是“左边打开”）
- `...default to 350ms Burst until a saved selection exists` 原译把条件翻反了 →
  **未保存过选择时：Model YL 默认单次发送，其他…默认 350 毫秒脉冲**
- `move-confirming states` 原译「确认移动的状态」→ **「已确认移动」状态**
- `best-effort` 直译「尽力而为」→ **仅供参考 / 即时发送一次**
- `Hosted host / C6 version` → **宿主 / 从机固件版本**（板子已是 C5，写 C6 会误导）
- `WI-FI` 全大写 → **Wi-Fi**（与全文一致）
- `Arduino-ESP32 core` → **Arduino-ESP32 核心库**
- `Bond repair armed` → **绑定修复待命**
- `Cancel pause` → **取消后暂停**；`Delay after AP` → **AP 结束后延迟**
- `0x239 View Range` → **0x239 可视距离**；`Auto Speed Scroll` → **自动滚轮调速**
- `ISA Suppression` → **ISA 限速提醒抑制**（原来写「提示音抑制」，没说清是限速提醒）

### 3. 补齐没翻的部分

- **239 条 JS 动态文案**：首页 AP 状态（辅助驾驶 · 自动转向 / 导航辅助驾驶…）、
  NAG 模式说明卡与标签、重连/重启遮罩、OTA 失败原因、S3XY 动作名与配对向导（6 段 HTML 模板）、
  各种 confirm/alert、状态行连接符
- **24 条 aria-label / placeholder**（原先完全没有翻，读屏软件和输入框提示都是英文）
- `<html lang="en">` → **`lang="zh-CN"`**（影响字体、断行、语音朗读）
- 固件消息 5 处：「左开」→「左变道开放」、「WiFi：」→「Wi-Fi：」、
  「ESP-Hosted C6」→「ESP-Hosted 从机」、`Hosted host / C6` → `宿主 / 从机`、
  「连续 AP 需要「车身 + 底盘」」补「拓扑」
