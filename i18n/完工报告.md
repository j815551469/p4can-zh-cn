## 三、下一步

### 1. 编译固件 —— 已完成（2026-11-13）

工具链已装好（arduino-cli 1.6.0 + ESP32 core 3.3.12，数据目录 `C:\arduino-data2`）。
重编只需一条命令：

```powershell
python tools\build_firmware.py
```

产物、SHA256 与“为何要暂存目录”见 `dist/BUILD-INFO.md`，工具链细节见
`i18n/工具链安装状态.md`。手编 FQBN：

```
esp32:esp32:esp32p4:ChipVariant=postv3,FlashSize=32M,PartitionScheme=app5M_fat24M_32MB,PSRAM=enabled,USBMode=hwcdc,CDCOnBoot=cdc,FlashMode=qio
```

### 2. 打包 APK

1. 安装 Android SDK + Gradle（zip 里没有 Gradle 工程，需要新建或复用 `android/Tesla-Unlock-1.2.1/tools/build.py`）
2. 把 `android/Tesla-Unlock-1.2.1` 作为模块导入
3. `values-zh-rCN` 会随系统语言生效；Java 字面量已直接中文化
4. 签名打包

### 3. 真机验证清单

- [ ] 手机连 `T2CAN-****`，打开 `192.168.4.1`，逐页检查中文无重叠/溢出
- [ ] 320 / 390 / 430 px 三档宽度
- [ ] 切换 Profile、保存、重启流程中文提示正确
- [ ] 固件返回的消息（OTA 失败、SSID 错误等）显示中文
