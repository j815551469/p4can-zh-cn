## 二、卡点（唯一未解决）

板子是 **ESP32-P4 + ESP32-C5-MINI-1U**（用户已看丝印确认）。
固件按作者参数（**P4 + C6**）编译，启动时报：

```
assert failed: verify_host_config_for_slave transport_drv.c:694 (0!=0)
E (5210) transport: Identified slave [esp32c5] != Expected [esp32c6]
Aborting..
```

原因：P4 无射频，Wi-Fi/BT 走 ESP-Hosted，从机型号在
`C:\arduino-data2\packages\esp32\tools\esp32p4-libs\3.3.12\qio_qspi\include\sdkconfig.h` 写死：

```c
#define CONFIG_ESP_HOSTED_IDF_SLAVE_TARGET "esp32c6"
```

## 三、B 方案：用 Arduino 核现成参数重编 esp_hosted（不动 IDF 全套）

### 版本基线（必须严格一致）

- ESP-IDF **v5.5.5**（`b774170ff46`）
- `espressif__esp_hosted` **2.12.13**
- 编译器：`C:\arduino-data2\packages\esp32\tools\esp-rv32\2601\bin\riscv32-esp-elf-gcc.exe`

### 步骤

1. **取源码**（esp_hosted 2.12.13）
   - 组件仓库：`https://components.espressif.com/components/espressif/esp_hosted/versions/2.12.13`
   - 或 GitHub tag `v2.12.13`。
   解压到 `C:\esp-hosted`。

2. **准备编译参数**
   - 直接复用 Arduino 核导出的：`...\esp32p4-libs\3.3.12\flags\c_flags`、`defines`、`includes`。
   - `includes` 里是 `-iwithprefixbefore <相对路径>`，前缀根是
     `C:\arduino-data2\packages\esp32\tools\esp32p4-libs\3.3.12\include`。
   - **额外**：
     - `-I<esp_hosted源码>/host`
     - `-I<esp_hosted源码>/host/api/include`
     - `-D CONFIG_ESP_HOSTED_IDF_SLAVE_TARGET_ESP32C5=1`（或按 2.12.13 的 Kconfig 实际宏名，
       先看 `host/port/esp_hosted_host_config.h` 里的 `H_SLAVE_TARGET_*` 分支）

3. **改配置**
   复制 `qio_qspi\include\sdkconfig.h` 为构建用配置，改：
   ```c
   #define CONFIG_ESP_HOSTED_IDF_SLAVE_TARGET "esp32c5"
   ```
   并把对应的 `CONFIG_ESP_HOSTED_SLAVE_...`/choice 宏同步（查看 2.12.13 的 `Kconfig`）。

4. **编译并打包**
   ```powershell
   # 对 host/ 下所有 .c 编译成 .o（flags 用 c_flags + defines + includes + 上面的额外参数）
   # 然后：
   riscv32-esp-elf-ar.exe rcs libespressif__esp_hosted.a *.o
   ```

5. **替换并重编固件**
   - 替换 `...\esp32p4-libs\3.3.12\lib\libespressif__esp_hosted.a`
   - 同步两份 `sdkconfig.h`（`dio_qspi`、`qio_qspi`）的 SLAVE_TARGET
   - 重编：
     ```powershell
     $env:ARDUINO_DIRECTORIES_DATA='C:\arduino-data2'
     D:\harness works\toolchain\arduino-cli.exe compile `
       --fqbn 'esp32:esp32:esp32p4:ChipVariant=postv3,FlashSize=32M,PartitionScheme=app5M_fat24M_32MB,PSRAM=enabled,USBMode=hwcdc,CDCOnBoot=cdc,FlashMode=qio' `
       --build-path 'C:\esp-build-c5b' --output-dir 'C:\esp-build-c5b-out' `
       'D:\harness works\P4-CAN-Universal-v3.29.3'
     ```

6. **刷 OTA 验证**
   ```powershell
   cd 'D:\harness works\p4can-zh-fork\dist'
   python -m esptool --chip esp32p4 -p COM3 -b 921600 write_flash --flash_mode qio --flash_size 32MB `
     0x10000 'C:\esp-build-c5b-out\P4-CAN-Universal-v3.29.3.ino.bin'
   ```
   然后 115200 读串口，看是否还出现 `Identified slave ... != Expected ...`。

## 四、已尝试且否决的做法（别再试）

- ❌ 把预编译 `.a` 里的 `esp32c6` 字符串替换成 `esp32c5`：
  日志变成 `[esp32c5] != [esp32c5]` 仍然 abort —— 比较的是**编译期枚举**，不是字符串。
- ❌ 只改 `sdkconfig.h`：库是预编译的，改头文件不影响库内枚举。
- ❌ 换 Arduino 核版本：索引里最新只有 3.3.12，没有 C5 版 P4 库。
