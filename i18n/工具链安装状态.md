## 继续安装的三条路（任选其一）

### A. 有代理/VPN 时（最快，2 分钟）

```powershell
$env:HTTPS_PROXY="http://<代理地址>:<端口>"
$cli='D:\harness works\toolchain\arduino-cli.exe'
& $cli core install esp32:esp32@3.3.12
```

官方索引已从配置里移除，需要先加回：

```powershell
& $cli config add board_manager.additional_urls https://espressif.github.io/arduino-esp32/package_esp32_index.json
& $cli core update-index
& $cli core install esp32:esp32@3.3.12
```

### B. 用本地归档装（无外网也能装）

```powershell
# 1) 起本地镜像
cd C:\esp-mirror
python serve.py            # 监听 127.0.0.1:8123

# 2) 用离线索引装
$env:ARDUINO_DIRECTORIES_DATA='C:\arduino-data'
$cli='D:\harness works\toolchain\arduino-cli.exe'
& $cli config set board_manager.additional_urls http://127.0.0.1:8123/index_local.json
& $cli core update-index
& $cli core install esp32:esp32@3.3.12
```

> 注意：目前离线索引里个别工具条目（`esp-x32` 的 x86_64 变体）仍会回退到 GitHub，
> 需要把 `make_index2.py` 的 MAP 映射改成**只保留 i686 归档**并确认 size/checksum
> 与本地文件一致（脚本已按本地文件重算，但 arduino-cli 某些版本会对重复工具条目取第一个）。

### C. 手工布局（兜底）

把 `esp32-core-3.3.12.zip` 解压到
`C:\arduino-data\packages\esp32\hardware\esp32\3.3.12`，
各工具解压到 `C:\arduino-data\packages\esp32\tools\<工具名>\<版本>`，
再手写 `installed.json`。

## 装完后的编译命令

```powershell
$cli='D:\harness works\toolchain\arduino-cli.exe'
$fqbn='esp32:esp32:esp32p4:ChipVariant=postv3,FlashSize=32M,PartitionScheme=app5M_fat24M_32MB,PSRAM=enabled,USBMode=hwcdc,CDCOnBoot=cdc,FlashMode=qio'
& $cli compile --fqbn $fqbn --output-dir 'C:\esp-build' 'D:\harness works\P4-CAN-Universal-v3.29.3'
```

产物：`C:\esp-build\P4-CAN-Universal-v3.29.3.ino.bin` 等；再用 esptool 合并成
`fullflash.bin`（0x2000 bootloader + 0x8000 分区 + 0x10000 app）。
