## 重新编译（一条命令）

```powershell
$env:ARDUINO_DIRECTORIES_DATA='C:\arduino-data2'   # 也可让脚本自动探测
python tools\build_firmware.py
```

脚本做的事：`build_dashboard.py` 重新生成 `index_html.h` → 把固件源码暂存到
`build/_src/P4-CAN-Universal-v3.29.3/` → `arduino-cli compile` → 两项内容级校验：

1. `tools/verify_build.py`：内嵌仪表板与 `dashboard_source.html` 逐字节比对；
2. TinyCrypt owner 契约（复用 `tools/verify_p4_crypto.py`）：确认
   `EccPoint_mult` 等符号来自 `src/p4_tinycrypt/*.o`、没有链入 stock `libbt.a` 成员。

产物在 `build/out/`。

**为什么需要暂存**：arduino-cli 要求 sketch 目录名与 `.ino` 主文件名一致
（`<目录名>.ino`）。本仓库目录叫 `p4can-zh-fork`，直接编译会报
`main file missing from sketch`。所以不能像旧文档那样直接对着仓库目录编，
也不能拿一份“去掉了 src/ 的副本”去编（2026-11-13 14:35 的旧产物就是这么来的，
详见 `dist/BUILD-INFO.md` 的差异说明）。`build/` 已加入 `.gitignore`。

## 手动等价步骤（排查时用）

```powershell
$env:ARDUINO_DIRECTORIES_DATA='C:\arduino-data2'
$cli='D:\harness works\toolchain\arduino-cli.exe'
$fqbn='esp32:esp32:esp32p4:ChipVariant=postv3,FlashSize=32M,PartitionScheme=app5M_fat24M_32MB,PSRAM=enabled,USBMode=hwcdc,CDCOnBoot=cdc,FlashMode=qio'

# 1) 生成中文仪表板头文件
python tools\build_dashboard.py

# 2) 暂存成合规目录名（tools/build_firmware.py 会自动做，这里演示手工做法）
robocopy . build\_src\P4-CAN-Universal-v3.29.3 /E /XD .git build dist i18n tools android __pycache__

# 3) 编译
& $cli compile --fqbn $fqbn `
  --build-path 'build\build' `
  --output-dir 'build\out' `
  'build\_src\P4-CAN-Universal-v3.29.3'

# 4) 校验内嵌中文仪表板
python tools\verify_build.py --bin 'build\out\P4-CAN-Universal-v3.29.3.ino.bin' --html dashboard_source.html
```
